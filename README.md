# US Metro Scoring Explorer

An interactive scoring explorer for **478 US metro and micro areas** (Census
[CBSAs](https://www.census.gov/programs-surveys/metro-micro.html)) with fully
configurable criteria weights. It started as a personal relocation-research
tool and is published here as-is in case the data and the scoring playground
are useful to anyone else.

Live site: served from this repo via GitHub Pages (see the *Deploy* workflow).

## What it does

- **Map** — a choropleth of all 478 included CBSAs, colored by the composite
  score (or any single group/metric). Grey areas are CBSAs that were screened
  out before scoring (summer humidity or airport access — hover for the
  reason); blank areas are simply outside any CBSA. The airport screen kept
  areas within 150 mi of an airport with nonstop Tokyo service, 110 mi of an
  airport with 1M+ annual boardings, or 60 mi of one with 250k+; the humidity
  screen cut areas with a July–August 3pm dew point of 65 °F or higher.
- **Control panel** — every scoring group and metric can be re-weighted,
  enabled, or disabled live. Custom configurations can be saved as presets
  (localStorage) or shared via the URL hash.
- **Ranked results + details** — a sortable ranking of all areas, with a
  per-group and per-metric score breakdown for any selected CBSA.

## How scoring works

Each metric is converted to a **0–100 percentile score across the 478
included areas** (direction-aware: for some metrics higher raw values score
better, for others lower). A group's score is the weighted mean of its
enabled metrics; the composite is the weighted mean of the enabled core
groups, plus small additive bonus groups. The app ships with a **baseline
configuration** of weights; a header badge confirms the live engine
reproduces the precomputed baseline scores exactly, and changes from the
baseline are yours to explore.

The criteria reflect the original personal use case — e.g. road-cycling
terrain and race scene, climate (with an aversion to hot-humid summers),
youth share and startup activity, housing value, air connectivity including
Tokyo routes, and bonus groups for Catholic/Orthodox presence and a
4,000–8,200 ft altitude band. Reweight or disable anything that isn't your
priority.

## Data

The JSON files in `public/data/` are **generated by a private data pipeline
and shipped prebuilt** — this repo contains the app and the exported data
only, not the pipeline. Sources, in general terms:

- **Census ACS & PEP** — demographics, migration, housing, income
- **NOAA/NCEI & PRISM** — climate normals (temperature, dew point, sun, snow)
- **GMTED2010** — terrain and elevation
- **FBI CDE & CDC WONDER** — crime and homicide
- **BTS T-100 & FAA** — air service and airport activity
- **Zillow, FHFA & ACS** — home values and housing costs
- **BEA RPP** — regional price parities (cost of living)
- **FEMA National Risk Index & EPA air quality** — environmental risk
- **US Religion Census** — religious adherence
- **USAC / BikeReg event calendars** — competitive cycling activity

Data vintages span roughly **2020–2026** and are mixed across sources. The
data is provided **as-is, with no guarantee of accuracy or fitness for any
purpose** — verify anything important against the primary sources before
acting on it.

## Development

```bash
npm install     # or: npm ci
npm run dev     # local dev server
npm run build   # typecheck + production build to dist/
npm run preview # serve the production build locally
```

Stack: Vite + React + TypeScript, zustand, maplibre-gl. The UI is fully
registry-driven by `public/data/metrics.json` — no metric or group ids are
hardcoded in the app.
